# Reuse status for version 1.0.0

No dataset-wide reuse license is specified in this version. Public download
availability is not a statement that every component has the same reuse terms.

- Frozen source text is attributed to the FDA through the source URLs in
  `data/manifest.json`. Consult the original provider's terms for those materials.
- Stage plans, reference annotations, evidence links and inventory metadata
  are separate curated components. Their annotation-reuse license remains
  pending author specification.

This file records the current status; it does not grant a new license or
assert ownership of the original FDA material. A future version may add
author-approved licensing terms. The fixed v1.0.0 snapshot will remain available.
